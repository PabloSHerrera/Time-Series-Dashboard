# Time Series Dashboard

A dashboard built to present time series data in a clear, visually engaging, and easy-to-interpret way. The project focuses on turning raw temporal data into visual insights that support decision-making.

## Objectives

- Load and prepare time series data
- Design visualizations that highlight trends and patterns over time
- Organize the visualizations into a coherent dashboard layout
- Apply data storytelling principles for effective communication

## Repository Structure

| File | Description |
|---|---|
| `Lab 11.ipynb` | Notebook with data preparation and dashboard construction |
| `series temporales.xlsx` | Time series dataset |

## Tech Stack

Python · pandas · Jupyter Notebook

## How to Run

1. Clone the repository:

```bash
   git clone https://github.com/PabloSHerrera/Time-Series-Dashboard.git
   cd Time-Series-Dashboard
```
2. Open `Lab 11.ipynb` and run all cells.
